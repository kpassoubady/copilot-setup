# Welcome to the GitHub Copilot 1-Day Training Course

Complete the setup before class to avoid delays.

## Course Overview

See the [GitHub Copilot 1-Day detailed outline](https://github.com/kpassoubady/copilot-setup/blob/main/catalog/github-copilot-1-day-outline.md) for the course objectives and schedule.

## Pre-Class Setup (Required)

1. Follow the [general setup guide for your operating system](https://github.com/kpassoubady/copilot-setup/blob/main/install.md).
2. Choose one track below.
3. Clone that track's repository and complete its OS-specific instructions.
4. Run the verification commands in the track guide.
5. Confirm that both Copilot inline suggestions and Copilot Chat work in your IDE.

### Choose your track

| Track                      | Project                              | Description                      |
| -------------------------- | ------------------------------------ | -------------------------------- |
| Java Track                 | Spring Boot Personal Expense Tracker | Web application with H2 database |
| Python Track               | FastAPI Personal Expense Tracker     | Web application with SQLite      |
| .NET Track                 | ASP.NET Core Personal Expense Tracker | Web application with SQLite      |
| Python Data Analysis Track | Data Analysis Pipeline               | Pandas, Matplotlib, Seaborn      |

The installation guide includes OS-specific instructions for Windows and macOS.

## Checklist Before Class

- [ ] GitHub account with Copilot access enabled
- [ ] Latest VS Code installed, or another supported IDE for your track
- [ ] GitHub Copilot authenticated in the IDE
- [ ] Copilot inline suggestions and Copilot Chat verified
- [ ] Selected track repository cloned
- [ ] Track-specific prerequisites completed:

| Track         | Prerequisites                                |
| ------------- | -------------------------------------------- |
| Java          | JDK 21 and Maven                             |
| Python        | Python 3.11 or later                         |
| .NET          | .NET 10 SDK and Entity Framework Core tools |
| Data Analysis | Python 3.9 or later with Jupyter Notebook    |
