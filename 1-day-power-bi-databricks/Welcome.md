# Welcome to GitHub Copilot for Reporting Analysts

Complete this setup before class so the course can focus on GitHub Copilot workflows rather than installation.

## Course Overview

This one-day course teaches GitHub Copilot through familiar SQL, DAX, Power BI, and Databricks-compatible reporting artifacts. GitHub Copilot is the curriculum; reporting analytics is the practice environment. The supported learner path uses Windows, Visual Studio Code, Git, GitHub Copilot, PowerShell, and Power BI Desktop. Prepared offline fixtures support activities that do not have approved Databricks access.

Review the [detailed course outline](https://github.com/kpassoubady/copilot-setup/blob/main/catalog/github-copilot-1-day-v2-holman-power-bi-databricks-track.md) for the objectives and schedule.

## Pre-Class Setup

1. Read the [main installation guide](https://github.com/kpassoubady/copilot-setup/blob/main/1-day-power-bi-databricks/install/install.md).
2. Follow the [Windows installation guide](https://github.com/kpassoubady/copilot-setup/blob/main/1-day-power-bi-databricks/install/install-win.md), which is the supported course path.
3. If you are preparing on a Mac, follow the [macOS preparation guide](https://github.com/kpassoubady/copilot-setup/blob/main/1-day-power-bi-databricks/install/install-mac.md) and arrange an organization-approved Windows environment for Power BI Desktop.
4. Confirm that your GitHub account has the assigned GitHub Copilot license and that Visual Studio Code shows both Chat and inline suggestions.
5. Open Power BI Desktop once in the approved Windows environment.
6. Run the [setup verification](https://github.com/kpassoubady/copilot-setup/blob/main/1-day-power-bi-databricks/quickstart-project/README.md).
7. If your delivery uses live Databricks access, verify only the organization-provided workspace and authentication flow.

Do not disable security controls or place client-sensitive information, credentials, tokens, or production data in prompts, repositories, screenshots, or course files.

## Checklist Before Class

- [ ] Organization-managed Windows environment available
- [ ] Current approved Visual Studio Code installed
- [ ] Git installed and available from a terminal
- [ ] PowerShell 5.1 or later available
- [ ] GitHub Copilot extension installed and enabled
- [ ] GitHub Copilot signed in with the licensed organization account
- [ ] Copilot Chat opens in Visual Studio Code
- [ ] An inline suggestion can appear in a temporary SQL file
- [ ] Power BI Desktop installed and able to open
- [ ] Prepared course materials available at the location supplied for class
- [ ] Optional Databricks workspace access confirmed when required
- [ ] Setup verification ends with `SETUP READY: required pre-class checks passed`
- [ ] No client-sensitive information or live credentials added to course materials
