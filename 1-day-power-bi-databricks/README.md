This is the standalone pre-class setup area for the one-day GitHub Copilot course that uses SQL, DAX, Power BI, and Databricks-compatible reporting artifacts. Complete these steps before class without adding client-sensitive data or production credentials.

## Verify Your Setup

Follow the [quickstart verification instructions](quickstart-project/README.md). A ready local setup ends with:

```text
SETUP READY: required pre-class checks passed
```

The script cannot verify Copilot account licensing, organization policy, prepared course-material access, or optional Databricks authentication. Complete the manual checklist it prints.
